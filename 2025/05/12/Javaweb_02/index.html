Mysql数据库

  • 数据库：DataBase，存储和管理数据的仓库

  • 数据库管理系统：操作和管理数据的大型软件

  • SQL：操作关系型数据库的编程语言，定义了一套标准

一、mysql概述

1.Mysql安装

  • 添加环境变量

  • 链接命令

    • 
mysql [-h数据库服务器的IP地址 -P端口号] -u用户名 -p密码

  • 创建一个数据库，本质上就是在mysql/data目录下创建一个文件夹

3.数据库管理工具

    • https://heuqqdmbyk.feishu.cn/wiki/FAa3wj0nYi4xGBksbFuchBK8nhe

    • database也可以替换成schema，字符集默认UTF-8

  • 创建表语法

    • create table tablename(
字段1 字段类型 [约束] [comment 字段1注释],
......
字段2 字段类型 [约束] [comment 字段2注释]
)[comment 表注释];

  • 表中字段约束

    • 约束：约束是作用于表中字段上的规则，用于限制存储在表中的数据。

    •  id int comment '用户id',
      在类型之后加入
      
      
 create table user(
    id int primary key comment '用户id',
    username varchar(50) not null unique comment '用户名',
    name varchar(10) not null comment '姓名',
    age int comment '年龄',
    gender char(1) default '男' comment '性别'
) comment '用户信息表'

2.DML语句

  • 数据库操作语言，对数据库表进行增删改查（Data Manipulation Language）

  • insert

    • -- 指定字段添加数据
insert into 表名(字段名1, 字段名2) values (值1, 值2); 
-- 全部字段添加数据
insert into 表名 values (值1, 值2, ...);
-- 批量添加数据（指定字段）
insert into 表名 (字段名1, 字段名2)  values (值1, 值2), (值1, 值2);
-- 批量添加数据（全部字段）
insert into 表名 values (值1, 值2, ...), (值1, 值2, ...);

    • 注意条件，无条件则更新所有表

  • delete

    • delete from 表名 [where 条件];

  • 条件查询

  • 分组查询

    • 聚合

      • 将一列数据作为一个整体，进行纵向计算

      • select count(job) from emp;

    • 分组

      • 通过group by关键字实现

      • where与having区别

        • 1.having 可以写聚合函数
2.having 是分组后进行筛选


        • 执行顺序：where > group by > having

  • 分页查询

    • limit关键字

      • limit 起始索引,查询记录数;

  • DCL数据库控制语言，权限等等，不多学
