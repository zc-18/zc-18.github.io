二、vue常用指令

1.v-for

  • 遍历的数组，必须在data中定义； 要想让哪个标签循环展示多次，就在哪个标签上使用 v-for 指令

2.v-bind

  • 插值表达式不可以写到标签内部，标签内部属性只能用v-bind来写

3.v-if与v-show

  • 都是用来隐藏元素或显示

  • 差异

    • v-show是将所有的标签都显示，只是设置displar为NONE
    • v-if只是把有的显示出来

4.v-model

  • 用于收集表单工作，双向设置数据方便获取与修改

    • 1.设置数据模型
2.在文本框配置数据模型

5.v-on

  • 用于绑定事件，添加事件监听

  • 语法

    • 1.绑定事件
v-on:事件名="方法名"
简写为  @事件名="…"
<button class="btn-query" v-on:click="queryEmp">查询</button>
<button class="btn-clear" @click="clearform">清空</button>

2.创建函数（和data函数同一级别）
methods:{
                queryEmp(){
                    console.log(this.searchform)
                },
                clearform(){
                    this.searchform={
                        name:'',
                        gender:'',
                        job:'',
                    }
                }
            }
