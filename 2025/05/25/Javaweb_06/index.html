js学习

  • 计算机脚本语言

一、核心语法

1.js脚本引入方式

  • 可以在页面任意地方定义，一般建议将js脚本放到页面底部

  • 内部脚本

    •   <script>
    //1.内部脚本
    alert("hello world");
  </script>

2.基础语法

  • 变量声明

    • 关键字
     声明变量 let
     声明常量 const
          *var关键字已经过时
     
let a;
a=10
console.log(a);
a=true;
console.log(a);

const b=10 ;
console.log(b);

  • 变量输出方式

    • 1.alert();弹窗
2.console.log();控制台输出
3.document.write();文本输出到html中


    • 反引号字符串便于字符串拼接
例如：
let name = 'TOM'
let age = 18;
console.log(`我是${name},我今年${age}岁`);

3.自定义对象

    • 在使用箭头函数匿名定义类函数时，需注意不要成为this只想当前对象父亲

5.DOM操作

  • 将标记语言的各个组成部分全部包装为对象

    • Document：整个文档对象
Element：元素对象
Attribute：属性对象
Text：文本对象
Comment：注释对象


    • <body>
  <h1>黑马程序</h1>
  <h1>黑马程序</h1>
  <h1>heoma</h1>
    <p>黑马程序是一个专业的IT培训机构，专注于为学生提供专业的IT课程。</p>
  <script>
    let h1 = document.querySelector('h1');
    console.log(h1);
    h1.innerHTML = '黑马程序yuan';

    let h = document.querySelectorAll('h1');
    console.log(h);
    h[2].innerHTML = "黑马程序aaaaa"
  </script>

    • import {printlog} from './js/demo1.js'
