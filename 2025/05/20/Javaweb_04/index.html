java数据库操作

一、jdbc操作数据库

1.入门

  • jdbc是java中操作数据库的底层代码

  • JDBC：(Java DataBase Connectivity)，就是使用Java语言操作关系型数据库的一套API

  • 数据库厂商自行提供jdbc接口的实现

2.入门程序

3.执行DQL查询语句

  • 处理结果时用到了指针的方式

  • dql语句返回ResultSet对象，类似于数组，DML语句返回数字，表示影响行数

4.sql预编译

  • 优点

    • 1.运行更加高效
    sql预编译语句会在内存中缓存起来，从而快速运行sql语句
2.可以防止sql注入

  • 编写mybits程序

    • package com.itheima.mybitsdemo;

@SpringBootTest // 测试类
class MybitsDemoApplicationTests {

    @Autowired
    private UserMapper userMapper;
    @Test
    public void contextLoads() {
        List<User> all = userMapper.getAll();
        all.forEach(System.out::println);
    }

}

2.数据库连接池

  • sun公司标准接口：DataSource

    • 常见产品（都是实现datasource接口）

  • 切换连接池

    • 引入德鲁伊依赖

      • <dependency>
    <groupId>com.alibaba</groupId>   
    <artifactId>druid-spring-boot-starter</artifactId>
    <version>1.2.19</version>
    </dependency>

3.增删改查操作

  • #{}与${}区别

    • ${}会产生sql注入，会直接拼接到sql注入

  • 新增语句

    • @Insert("insert into user(username,password,name,age) values(#{username},#{password},#{name},#{age})")  //大括号里面写属性名
public void insert(User user);

  • 查询操作

    •     @Select("select * from user where username=#{username} and password=#{password}")  //大括号里面写属性名
    public List<User> select(String username ,String password);

  • 执行方式

    • class MybitsDemoApplicationTests {

    @Autowired
    private UserMapper userMapper;
    @Test
    public void contextLoads() {
        User user = new User(1,"admin","123456","管理员",18);
        userMapper.insert(user);
    }

    • 插件mybatisX

      • 迅速定位mapper

5.springboot配置文件

  • 配置文件一般有俩类（yml与yaml文件相同）

  • application.properties文件太过复杂臃肿存在大量重复代码

    • spring.application.name=mybits-demo
mybatis.configuration.log-impl=org.apache.ibatis.logging.stdout.StdOutImpl
mybatis.mapper-locations=classpath:/mapper/*.xml
# 数据库连接配置
spring.datasource.url=jdbc:mysql://8.152.199.9:3306/db_test
spring.datasource.username=root
spring.datasource.password=123qwe!@#QWE
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

    • 层级结构更加清晰

  • 另外：如果其定义字符串前有0，需要加引号，防止被识别为八进制数值
