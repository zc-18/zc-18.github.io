Maven项目构建工具学习

  • maven是一款管理和构建java项目的工具

1.maven作用

  • 依赖管理

    • 只需要用标记语言描述即可导入jar包

  • 项目构建标准

    • 提供的插件直接点击即可，跨平台
      • compile编译
      • package打包

  • 提供同一项目结构

    • 依靠maven开发项目，所有idea软件都可以
      • 结构如下

2.maven介绍

  • Apache Maven 是一个项目管理和构建工具，它基于项目对象模型(POM)的概念，通过一小段描述信息来管理项目的构建。

  • 模型介绍

  • 仓库

    • 仓库：用于存储资源，管理各种jar包。
本地仓库：自己计算机上的一个目录。
中央仓库：由Maven团队维护的全球唯一的。 仓库地址：https://repo1.maven.org/maven2/
远程仓库(私服)：一般由公司团队搭建的私有仓库。

3.maven项目构建与导入

  • maven坐标

    • Maven 中的坐标是资源(jar)的唯一标识，通过该坐标可以唯一定位资源位置。
使用坐标来定义项目或引入项目中需要的依赖。

4.maven依赖管理详解

  • 导入依赖

    • 1.定义dependences标签
2.在该标签中定义dependence标签
3.在标签中定义三个坐标
4.点击刷新按钮，导入依赖

依赖坐标寻找
可以到官网
https://mvnrepository.com/寻找

    • 同时，依赖会传递，spring-context会依赖许多依赖

  • 排除依赖

    • 主动断开资源

    • <dependency>
                <groupId>org.springframework</groupId>
                <artifactId>spring-context</artifactId>
                <version>6.1.4</version>
        </dependency>
        exclude>
            <artifactId>spring-core</artifactId>
            <groupId>org.springframework</groupId>
        </exclude>
        排除依赖无需指定版本号

5.常见注解

  • 这几个注解顾名思义

  • 参数化测试注解

    • 为了有更多的参数进行测试，更加完美

    • public class UserServiceTest {
    @ParameterizedTest
    @ValueSource(strings = {"110101199001011234", "110101199001011236"})
    public void testgetGender(String id_card){
        UserService userService = new UserService();
        String age = userService.getGender(id_card);
        Assertions.assertEquals("男", age);
    }
}

6.单元测试-企业开发规范

  • 最好要考虑所有的边界情况
  • 可以通过idea中提供的一个按钮进行查看覆盖率
  • 如果只是想要统计某一个类，可以编辑配置
  • 也可以通过侧边按钮通过ai一键生成测试类

7.单元测试范围

  • 一般情况下在哪里都可以些

  • 可以设置maven中junit的scope标签，让其只能在某一处进行

  • **一般都是test，仅仅在测试目录下生效 **

  • 一般依赖报错，联网下载一半网络不好导致jar包错误

    • 解决方法

    • 把所有jar包下的.LastUpdated文件删除就ok

    • del /s *.lastUpdated
