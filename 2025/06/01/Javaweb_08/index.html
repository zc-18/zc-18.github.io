4.api风格

  • 选项式api

    • <script>
export default {
  data(){ //声明响应式对象
    return {
      count: 0
    }
  },
  methods: { //声明方法，可以通过组件实例访问
    increment: function(){
      this.count++ ;
    }
  },
  mounted(){ //声明钩子函数
    console.log('Vue mounted ...');
  }
}
</script>
<template>
  <button @click="increment">count:{{ count }}</button>
</template>

    • 比较随性，自行定义
