一、多表关系

1.多表关系

2.解决方案

  • 一对多

    • 在数据库表中多的一方，添加字段，来关联一的一方的主键

  • 一对一

    • 在某一方添加一个字段，关联对方的主键（并且设置为unique）

  • 多对多

    • 需要新创建一个表实现

3.物理外键

  • 现在已经不推荐，使用逻辑外键

  • 也可以使用图形化界面添加

  • 通过右击表，点击showdiagram可以展现俩张表直接关系

  • 使用物理外键约束后，更新父表会受限，从而保证数据一致性

二、多表查询

1.定义

  • 多表查询: 指从多张表中查询数据

  • 直接使用select * from dept,emp;会出现笛卡尔积

    • 即将所有情况全部组合

  • 加入约束，select * from dept,emp where dept.id = emp.dept_id;即可获取正常结果

2.分类

  • 连接查询

    • 内连接（查询交集部分级）

      • 隐式内连接

      • 查询交集部分级
select * from dept,emp where dept.id = emp.dept_id;

    • 外连接

    • 左外连接与右外连接
    完全查询左边与完全查询右边
select 字段列表 from 表1 left [outer] join 表2 on 连接条件 ...;  
select emp.name,dept.name from emp left join dept on emp.dept_id = dept.id;

    • 列子查询

      • select emp.name,dept.name from emp,dept 
    where emp.dept_id=dept.id and 
    dept_id in (select id from dept where name = '教研部' or name = '咨询部');
返回一个列

    • 表子查询

      • select * from emp e,(select dept_id,max(salary) max from emp group by dept_id) a 
where a.dept_id = e.dept_id
and a.max = e.salary;   
返回一个表

  • 具体实现

  • 创建实体类封装具体每页数据

    • public class PageResult {
    private Long total; //总记录数
    private List<Emp> list; //当前页数据列表
}


    • controller

@Slf4j
@RequestMapping("/emp")
@RestController()
public class EmpController {
    @Autowired
    EmpService empService;
    @GetMapping
    public Result getEmp(@RequestParam(defaultValue = "1")Integer page,@RequestParam(defaultValue = "10")Integer pageSize){
        log.info("查询员工,参数:{},{}",page,pageSize);
        PageResult<Emp> pageResult = empService.getEmp(page,pageSize);
        return Result.success(pageResult);
    }
}

  • pagehelper插件实现

    • 引入依赖

      • <!--分页插件PageHelper-->
<dependency>
       <groupId>com.github.pagehelper</groupId>
       <artifactId>pagehelper-spring-boot-starter</artifactId>
       <version>1.4.7</version>
</dependency>

    • 注意点

      • sql语句不能加分号
      • 仅对跟在后面的第一个sql语句查询生效

    • 原理

      • a.select count(0) from emp e …

        b.select … from emp e … limit ?,?

      • 拦截修改sql语句

2.条件分页查询

  • 知识点

    • 字符串拼接

      • 在查询条件时如果有需要用到引号，可以使用concat函数

        • '%#{name}%'
concat('%', #{name}, '%')

    • 传参优化

      • 可以用一个实体类封装传参数据

    • 动态sql

      • sql语句随外部变化

        • if标签，and语句会报错，不推荐


        •         <where>
            <if test="name != null">
                e.name like concat('%', #{name}, '%')
            </if>
            <if test="gender != null">
                and e.gender = #{gender}
            </if>
            <if test="start != null and end != null">
                and e.entry_date between #{start} and #{end}
            </if>
        </where>

    • 一个小知识点， Closing non transactional SqlSession通常是sql语言配置文件出错
