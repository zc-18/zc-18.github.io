一、会话保持技术

  • 登录标记：用户登录成功之后，在后续的每一次请求中，都可以获取到该标记。 【会话技术】
  • 会话：用户打开浏览器，访问web服务器的资源，会话建立，直到有一方断开连接，会话结束。在一次会话中可以包含多次请求和响应，会话跟踪：一种维护浏览器状态的方法，服务器需要识别多次请求是否来自于同一浏览器，以便在同一次会话的多次请求间共享数据。
  • 思路

1.cookie技术

  • 存储于客户端

    • 优点：HTTP协议中支持的技术
缺点：

 不安全，用户可以自己禁用Cookie
 Cookie不能跨域

二、统一拦截技术

  • 本项目鉴权流程

1.过滤器Filter

  • 定义

  • 实现方式

    • 定义Filter，实现接口

    • 配置，@WebFilter注解实现类，@ServletComponetScan注解引导类

    • *filterchain.doFilter()放行，@WebFilter(urlPatterns = "/*")设置拦截地址，/表示拦截所有请求

  • 项目实践代码

    • @WebFilter(urlPatterns = "/*")
public class tokenfilter implements Filter {

    @Override
    public void doFilter(ServletRequest servletRequest, ServletResponse servletResponse, FilterChain filterChain) throws IOException, ServletException {
        HttpServletRequest httpServletRequest = (HttpServletRequest) servletRequest;
        HttpServletResponse httpServletResponse = (HttpServletResponse) servletResponse;//转化为http类数据
        String url = httpServletRequest.getRequestURI();
        if (url.contains("/login")){
            filterChain.doFilter(httpServletRequest,httpServletResponse);
            return;
        }
        // 1. 从请求头中获取 token
        String token = httpServletRequest.getHeader("token");
        if (token == null || token.isEmpty()){
            httpServletResponse.setStatus(401);
            httpServletResponse.getWriter().write("token is null");
            return;
        }
        // 2. 校验 token 是否有效
        try {
            JwtUtils.parseJWT(token);
        } catch (Exception e) {
            httpServletResponse.setStatus(401);
            return;
        }
        // 3. 校验通过，放行
        filterChain.doFilter(httpServletRequest,httpServletResponse);
    }
}
