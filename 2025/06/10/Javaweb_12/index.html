Javaweb-员工创建与文件上传

发表于2025-06-10|更新于2026-11-17|Javaweb
|总字数:1.4k|阅读时长:6分钟

web后端开发进阶

一、新增员工

1.知识点

  • 批量插入数据

    • 使用xml中foreach标签

    •     <insert id="insertBatch" >
        insert into emp_expr (emp_id,begin,end,company,job) values
        <foreach collection="list" item="empExpr" separator=",">
            (#{empExpr.empId},#{empExpr.begin},#{empExpr.end},#{empExpr.company},#{empExpr.job})
        </foreach>
    </insert>

    • 这样再插入数据时将会返回id值

2.具体实现

  • mapper

    • @Mapper
public interface EmpMapper {
    List<Emp> list(EmpQueryParam q);
    @Options(useGeneratedKeys = true,keyProperty = "id")
    @Insert("insert into emp(username, name, gender, phone, job, salary, image, entry_date, dept_id, create_time, update_time)" +
            " values (#{username}, #{name}, #{gender},#{phone},#{job},#{salary},#{image},#{entryDate},#{deptId},#{createTime},#{updateTime})")
    void insert(Emp emp);
}

  • controller

    •     @PostMapping
    public Result save(@RequestBody Emp emp){
        log.info("新增员工,参数:{}",emp);
        empService.save(emp);
        return Result.success();
    }

    • 要不全部失败，要不全部回退

  • spring中事务管理注解

    • 注解：@Transactional

      作用：将当前方法交给spring进行事务管理，方法执行前，开启事务；成功执行完毕，提交事务；出现异常，回滚事务

    • 可以定义在方法，类，接口

  • 单独开启事务管理日志

    • 配置日志信息,查看spring事务管理的底层日志

    • logging:
  level:
   org.springframework.jdbc.support.JdbcTransactionManager: debug

    • 不会回滚

    • 设置参数既可实现所有异常回滚

      • @Transactional(rollbackFor = Exception.class)

      • 默认为requird，表示加入到另外一个事务，设置为new表示挂起当前事务，自己单干

  • 事务的四大特性

三、文件上传

1.基础

  • 前端代码实现

    • <form action="/upload" method="post" enctype="multipart/form-data">
    姓名: <input type="text" name="name" > <br>
    年龄: <input type="text" name="age" > <br>
    图像: <input type="file" name="file" > <br>
    <input type="submit" value="上传文件" name="submit"></form>

    • 在请求时会在temp目录下临时产生上传文件

2.本地存储实现

  • 文件大小限制

    •   servlet:
    multipart:
      max-file-size: 10MB//最大单个文件
      max-request-size: 10MB//最大请求大小
  


* ~~~java
      @PostMapping("/upload")
      public Result upload(MultipartFile file) throws Exception {
          String originalFilename = file.getOriginalFilename();
  
          String url = aliyunOSSOperator.upload(file.getBytes(), originalFilename);
          return Result.success(url);
  
      }

    • 具体实现

      • application.yml

aliyun:
  oss:
    endpoint: https://oss-cn-beijing.aliyuncs.com
    bucketName: java-ai0514
    region: cn-beijing

    • 深层实现

      • 定义实体类
@Data
@Component //事务管理
@ConfigurationProperties(prefix = "aliyun.oss")//指定类
public class AliyunOSSProperties {
    private String endpoint;
    private String bucketName;
    private String region;
}
